## Zen mode

A distraction-free VS Code setup for practice sessions in the `.run/` folder (the `.run/` folder must be created locally):

- Black text only (same theme and font, no syntax colors).
- No auto completion, snippets, parameter hints or inline suggestions in `.py` files.

Turn it on by opening the workspace file (only `.run/` will be shown in the sidebar):

```bash
code config/focus.code-workspace
```

Turn it off by opening the repository folder again (`code .` or **File → Open Recent**). Your normal settings are never modified.

See: [focus.code-workspace](./config/focus.code-workspace)
